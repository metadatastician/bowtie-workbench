= Bowtie Workbench
:toc:

A local-first risk and opportunity workbench for understanding how work succeeds,
how control can be lost, and how organisations learn. Owned by
https://github.com/metadatastician/bowtie-workbench[metadatastician].

== Start here

Open link:src/prototype/index.html[the supplied interface] in a modern browser,
or run `just run` (Bun 1.3.14) and visit http://127.0.0.1:8080.
It includes bowties, causal chains, harm domains, barriers, opportunities,
appetite decisions, review history and learning records. Data stays in browser
IndexedDB; use the interface's JSON export to keep a portable backup.
Browser storage belongs to the URL/origin; opening the file and serving it use
different stores. The imported HTML is byte-for-byte the supplied Downloads file.

== Working implementation and its limits

* Implemented: supplied HTML/CSS/JavaScript interface and browser persistence.
* Implemented: small AffineScript policy kernel in `src/core/policy.affine`.
  `just test` type-checks it, compiles actual WebAssembly and executes its exports
  against boundary cases. Bun is the host/test runtime.
* The interface still executes its original JavaScript policy. Replacing that
  boundary with the AffineScript module is the next integration milestone.
* AnyType and System ET are pinned architectural dependencies, not linked runtime
  libraries or completed proofs. No database server, collaboration service,
  quantitative risk engine, certification or production deployment is claimed.

To build the policy kernel, build the compiler at the revision in
link:.machine_readable/dependencies.json[dependencies.json], then set
`AFFINESCRIPT_BIN=/path/to/affinescript/_build/default/bin/main.exe`.
A sibling `../affinescript` checkout is the local default. Run `just test` and
`just validate-rsr`. The compiler is required: missing tooling fails the build.
Build outputs go to `BOWTIE_BUILD_DIR`, defaulting under the developer estate's
`llm-coding-configs/codex/bowtie-workbench-build` (CI supplies its temporary path).

This application uses https://github.com/hyperpolymath/affinescript[AffineScript].
https://github.com/hyperpolymath/anytype[AnyType] supplies the proposed graded kernel;
https://github.com/hyperpolymath/systemet[System ET] owns its theory and invariants.
Bowtie Workbench owns the domain model and user workflow, and does not redefine
the upstream type theory. It was instantiated using the authoritative
https://github.com/hyperpolymath/rsr-template-repo[RSR template] and `just repo-init`.
Its descriptive metadata lives in `.machine_readable/descriptiles/`.

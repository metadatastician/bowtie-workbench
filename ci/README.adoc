= Continuous integration

the pinned AffineScript compiler and executes the real WebAssembly policy tests.

`ci/rsr-reference/`: container publishing, pages, email, mirrors, Rust builds,

This is initial project configuration, not a claim that those services passed.
No publishing or message-sending workflow is active.

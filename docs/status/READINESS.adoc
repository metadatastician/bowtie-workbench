= Readiness

Stage: experimental foundation. The supplied interface is retained. The initial
policy module type-checks, compiles and has executable WebAssembly tests. Source
pins identify inspected upstreams; a cached local compiler is not by itself proof
of a reproducible clean build. CI is configured to build from that source pin.

The browser has not yet been switched to the AffineScript policy. Database-server,
collaboration, simulation and AnyType runtime integration are planned. Application
proof obligations are documented, not discharged. No production deployment,
quantitative validity or external safety assurance is claimed.

Inherited Idris2/Zig/container/proof assets are reference scaffolding, outside the
declared baseline capability. Their presence is not implementation or proof.

= Roadmap

. Preserve the supplied interface, instantiate RSR, execute an AffineScript core.
. Specify the existing JSON schema; add migration and malformed-input fixtures.
. Differentially test the JavaScript appetite rules against AffineScript and wire
  the module into the interface without changing decisions or storage semantics.
. Implement typed evidence, control verification, stable IDs, provenance and time.
. Extract the causal graph, shared dependencies, temporal feedback and alternative
  explanations. Add organisational levels and work-as-done observations.
. Build closed-loop learning and practitioner evaluation with realistic scenarios.
. Add uncertainty and decision-analysis libraries only after numerical semantics,
  dependency assumptions and validation benchmarks are established.

Initial vertical slice: one hazard, one loss-of-control event, two threats sharing
a dependency, two consequences, a critical barrier with expiring evidence, and a
learning action whose attempted closure is rejected until verification is present.
